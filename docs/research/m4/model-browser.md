# The model browser [verified offline]

The list a block's model is chosen from: its view, rows, levels, categories and items. Status tags as in [conventions.md](../conventions.md).

The list a block's model is chosen from. Found by disassembly; the per-model costs below were checked by running the firmware's own lookup and cost functions in unicorn on the stock Entry 0 (`tests/test_dsp_meter.py`).

- **View**: `0x281299d0`, list B (it replaces the Edit view's top half), constructor `0x28d90f34`, paint `0x28dc4dd0` (literal `0x28d96df0`, `0x28dc4dd1`), event handler `0x28dc4ed4` (literal `0x28d96dec`). Its paint erases and draws a few image widgets (`Icon_ArrowRight` at (290, 194); scrollbar ends `Icon_ScrollbarTop`/`Bottom` at x 310 with a 5-px track at `+0x4d4`; three `Button_*` pictures at x 53, 160, 267, y 81), an icon list at `+0x44` and a text list at `+0x6c`, under the widget lock.
- **Rows**: five a page, 40 px apart from y 194. The icon list (ROM widget: init `0x10001fa8`, draw `0x10001f08`, setImage(row) `0x28e24be8`, setVisible(row) `0x28e24b20`) is `{count 5, selected, x 21, y 194, pitch 40, anchor 7, images, items, nodes}`; its items are ordinary image widgets at `view + 0x22c + 0x24 * row`, each with its own position (`y = 194 - 40 * row`, anchor 7: top centre). The text list (`+0x6c`: x 44, set only by the constructor's `movs r3, #0x2c` at `0x28d90f72`, anchor 6; row buffers of 0x11 bytes at `+0x3d0`) holds the names (setText(row) `0x28e24c88`, setColor(row) `0x28e24ba0`). ROM setImage (`0x10001d14`) marks a visible item dirty whether or not the image changed, so every fill redraws every visible row's icon. Rows have no highlight: the background between icon and name is black. The category icons (`Icon_Dist` etc., 22..36 px wide, so at most x 3..39) are thin coloured line art on black, and their Off versions the same in grey.
- **Levels**: the byte `view + 0x40` picks the fill (dispatch at `0x28dc4d58` and in the constructor): 1 `0x28dc3704`, **2 `0x28dc3424`, the models**, 3 `0x28dc392c`, 4..6 `0x28dc31d8` (the categories, from `0x28d9e048`), anything else `0x28dc3a2c`.
- **Categories**: two tables of 0x2c-byte records `{name[0x11], short[0xb], colour, dim colour, icon, icon off}`: the block categories at `0x28e2815c` (`0x28d9e01c(cat, out)`, 0..0x19: Input, Output, Split, Join, Distortion, ...) and the browser's at `0x28e285d4` (`0x28d9e048(cat, out)`, 0..0x12: None, Favorites, Distortion, Dynamics, EQ, Modulation, Delay, Reverb, Pitch/Synth, Filter, Wah, Amp+Cab, Amp, Preamp, Cab, IR, Volume/Pan, Send/Return, Looper).
- **The model level** (`0x28dc3424`): `0x28df0280(&level)` (it takes and releases the DSP model lock) gives a level byte; the list is category `[view + 0x56e + level]`, subcategory `[view + 0x570 + level]`; row r shows item `[view + 0x569] + r` while that is below `0x28e0edcc(cat, sub)`, the list's length (the counts at `0x28e3e13c`). `0x28e0f220` sets the icon from the item's fits flag: the category's icon, or its Off icon and grey text for a model that would not fit (Amp+Cab, Cab and IR lists choose dual icons by subcategory).
- **Items**: `0x28e01204(cat, sub, i, &item)` gives `[0x28e3e00c + 4 * (4 * cat + sub)] + 0x30 * i` (null lists, e.g. Favorites, have length 0). An item is a block-load descriptor `{u32 kind, u32 model, u32 second model or -1, u16, name[0x11] at +0xe, ..., fits at +0x28}`, so `0x28e01d50(item, &cost)` prices it: Kinky Boost 509, WhoWatt 100 (Amp+Cab, kind 0x21) 2629 + its cab's 250 = 2879. The Static Model Table is not sorted in the file: boot quicksorts it (the code around the literal `0x28e01c08`), and `0x28e01d50`'s binary search fails (`-0x15`) on the unsorted table.
- **Model titles** [verified offline]: every copy of a model's title in Entry 0 is in two tables, Table 2's 16-byte short name (row + 4; `patch_amp.py` `TAB2_BASE_PTR`) and each browser item's name (+0xe; stock names are at most 16 characters, the bytes up to +0x28 zero). Entry 3's `displayName` is a third copy, which the M4 doesn't show: with only the two Entry 0 tables renamed (`tools/features/real_names.py`), the model browser and the Edit view's block title both show the new names, and a 16-character title ("Shin-ei Uni-Vibe", "Mark IV Rhythm 1") fits the Edit view's top strip [verified on unit, RAM boot 2026-11-11, "real-names boot-2"]. Two stock titles are longer than the short name: "Mandarin Bass 200" is "Mandarin Bass 20" there and "Mandarin Bass200" in the browser. Four Legacy cabs (`HD2_Cab1x12CaliExt`, `HD2_Cab1x12CaliIV`, `HD2_Cab1x12DelSol`, `HD2_Cab1x18DelSol`) carry another cab's title, "4x12 SoloLead EM", with their own names only in the browser.
