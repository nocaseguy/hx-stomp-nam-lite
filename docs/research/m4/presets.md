# Preset storage and the preset file

The fixed-slot stores on the eMMC and the layout of a preset file. Status tags as in [conventions.md](../conventions.md).

- **Preset storage** [verified offline]: fixed-slot stores of numbered files (`fs_init 0x28daa4dc`; file `id` at sector `base + blk * id`, `mla` at `0x28daaafa`; a slot is a 0x18-byte header of two `{len, seq, crc}` copies, then two ping-pong data copies of at most `(blk * 512 - 0x18) / 2` bytes). Open `0x28daaad8(fs, id, mode, handle, flag)`, read `0x28daa268`, write `0x28daa368`, seek `0x28daa2d8`, commit `0x28daa1e4`, delete `0x28daa608`. Stores: Presets at sector `0x1ef53` (0x200 sectors a file, 0x402 files; fs `0x2822f630`), Raw Presets `0x9f353`, Setlists `0x1eeb3`, Globals `0x1ee13`, IR `0x1dc11` (0x24 sectors, 128). A preset's file id is `dir[perm[slot]].id` (`0x28df1970`); moving a preset permutes `perm`, so its id goes with it. 126 presets a setlist.
- **A preset file** [verified offline] (`0x28df2060(id)`): `0xa9 "l6-helix\0"`, a TOC (`0xda 00 30` + twelve absolute offsets, written zero at `0x28df20ea` and again after the serializer at `0x28df210a`, after a seek to 10, which leaves the file at 0x3d), then at 0x3d a fixmap of `(0x28e026f0(preset, 1) + 9) | 0x80` keys: 7, 0 (the blocks), 1, 3, 4, 2, 5, 6, 10 (snapshots), and 12 (128 names) when that flag is set. The load reads sections by the TOC (`0x28def9a8(file, n, 0, buffer, 0x5000)`), not by walking the map; section 10 is everything from the end of key 10 to the end of the file, and its parser `0x28deb410` reads only as far as key 12's names (without key 12 it returns -3, the same as no names). HX Edit's download sends the file whole; its upload stores the bytes as sent (length under 64 KiB).
