# Snapshots

The snapshot manager and its records, select, its callers, the snapshot footswitch mode and the snapshot icon. Status tags as in [conventions.md](../conventions.md).

- **The snapshot manager** is a static object at `0x2812c630` (`0x28d960a4()`). `+4` is its lock (`0x28e24c00` lock, `0x28e24bb0` unlock, called with `manager + 4`), and it holds **three 0x260-byte records inline** at `+0xc + 0x260 * i`. After them come 20 block-enable bytes at `+0x72c`, the controller count at `+0x741`, the footswitch-entry count at `+0x742`, the current snapshot at `+0x743`, the previous one at `+0x744` and a busy byte at `+0x9a9`. About 35 functions index the records with `mov #0x260; mla`, so the array can't grow in place.
- **A record**: block states at `+0x00..0x13`; controller entries, 7 bytes each, from `+0x28` (value at `+1`, count `+0x741`); footswitch entries, 9 bytes each, from `+0x1e8` (switch index, then the bytes `0x28de672c` writes into the footswitch manager `0x28d96094()` at `+0x81 + 7 * switch`; count `+0x742`); a valid byte at `+0x24b` (0 until the snapshot holds a sound); tempo at `+0x250`; the name at `+0x255` (11 bytes, default `SNAPSHOT n`). `0x28de14b4(manager, record, name)` writes a record's defaults and takes the lock itself. `0x28de12d4(manager, to, from, with_name)` copies one.
- **Select** `0x28de2f90(manager, index)`: returns 0 while `+0x9a9` is set, and does nothing for an index above 2. On a new index it stores the old one in `+0x744`. It then sets block states against the live DSP, sends every controller value, and writes the footswitch entries (it compares them with the old record's only to decide whether to refresh). An unused record (valid 0) is first filled from the old one (`0x28de12d4(..., 0)`, name kept). On the current index, setting **ID 103 Reselect Snapshot** decides: 0 recalls it again, otherwise it goes back to the previous one.
- **Snapshot footswitch mode** [verified on unit]: a press reaches select through the footswitch-function dispatcher `0x28dd14a0(state, switch)` (called with switch 0, 1, 2 at `0x28dd18d4`, `0x28dd18fa`, `0x28dd190c` by bits 0..2 of an event mask; function byte at `0x28128a74 + 2 * switch`, table at `0x28dd14e4`). Function 14 (`0x28dd16b0`) is snapshot k for footswitch k; 7 next and 8 previous (wrapping) share its tail call `b.w select` at `0x28dd1640`. Pressing the lit one calls select with the current index, which Reselect Snapshot then handles. Found with a probe image (MD5 `f025b397…`) that counted the hook's entries and every select: in that mode `0x28de59a8` was never reached.
- **Callers**: the footswitch snapshot action `0x28de59a8(fsw, switch, which)` reads an action byte at `fsw + 7 * switch + 0x81 + (which ? 2 : 3)`: 1 next, 2 previous, 3..5 snapshots 1..3, which it tail-calls at `0x28de59d8` (`b.w select`). Other callers: MIDI CC 69 in the CC handler `0x28d9b120(cc, value)` (0..2, 8 next, 9 previous), the HX Edit command `0x58` (`0x28e1bfc4`, registered at `0x28e1e2c0`), and the Copy/Swap Snaps menu (`0x28de17c0` copy, `0x28de1888` swap).
- **Presets store snapshots as msgpack**, with integer keys. The parser `0x28de42c4(manager, buf, len, ...)` resets the records, then reads an array of snapshot maps with **no bound on its count**: a preset with more than three would overwrite the manager's fields after the records on stock firmware. The writer `0x28de3c9c(manager, stream, flag)` writes a fixed `0x93` (three), takes no lock, and has two callers (`0x28dea9fa`, `0x28deaf36`).
- **The snapshot icon** [verified offline]: the top view's image widget at `0x2812aae0 + 0x308` (node `+0x32c`), top left (262, 237), anchor 6, 52x35: a camera with the number in a circle (inside x 278..304, y 204..232; the digit white, rows 208..228). It shows `Icon_Snapshot1..3` (table `0x28e3add4`) or `Icon_Snapshot1Red..3Red` (`0x28e3adc8`, the outline red, the digit still white) by the current snapshot (`0x28dc9edc`, `0x28dca276`). The image store has `Icon_Snapshot4` (the XL's) but no 5 or 6. **[verified on unit]** The footswitch names are not a reliable bank marker after a flip.

How presets store them: [presets.md](presets.md). Six snapshots: [features/more-snapshots.md](../features/more-snapshots.md).
