# Metronome (`HX_CLICK=1`, `tools/patch_click.py`, `src/sharc/click.asm`, `tools/features/metronome.py`, `src/m4/metronome.s`)

A click-track block, Looper > Metronome, with a tempo-synced Time and its own DSP kernel. Status tags as in [conventions.md](../conventions.md).

- A mono effect, Looper > Metronome > Metronome (preset ID 181, DSP cost 50; modulation, not delay, so no trails), on a copy of the mono effect host whose member is primitive `0x0128` (registry `0x200050`; NAM has `0x9c75`). Knobs: Time (1/4 by default, synced), Level (dB, −14 by default), Accent (Off, 2..12: a 2 kHz downbeat every n beats), Thru (On passes the input). Its map is Simple Delay's sync chain without the `0x2d` node: the clamp's output is the kernel's pid 5.
- **Browser** [verified on unit, RAM boot 2026-11-11, MD5 `d436279a…`: Looper shows Mono, Stereo and Metronome, the block loads from there, Modulation is stock, a preset saved with the Modulation build keeps its Metronome]: a third Looper folder, Metronome, beside Mono and Stereo (Looper had two of its four). Its item is the Tremolo source's, block kind (btype) 1, a plain effect, where Looper's own items are kind 22. Earlier builds listed it as Modulation's fourth folder.
- **Its look** [verified offline; on unit, RAM boot 2026-11-11, MD5 `72154fc3…` and `a52307ad…` (Level −14 dB by default): teal in the signal flow, lit when on and dim when off, the metronome icon, dimmed when off; loopers, Mod and Volume blocks as stock; a saved preset keeps it]: two categories decide it. (1) The signal flow's slot picture is `table[slot category * 6 + state]` (`0x28e3abdc`; set at `0x28dc992c`), the slot category being the *browser* category in the block's info (`0x28e0fe94` → `0x28e0fafc`: the block record's halfword +0x14 to info +0xc; the info's bytes 1..4 are the preset model ID). It is stored in the UI's slot model at `+0x37` only at `0x28dd3046` (`ldrb.w r2, [sp, #0x10]; strb.w r2, [r3, #0x37]`); the other writers move it between slots. Looper (`0x12`) takes its own path (`0x28dc994a`): the grey `Block_LooperThumb` pictures with the looper's on/off, so under Looper the Metronome showed dim grey whether on or off [verified on unit, `d436279a…`]. `src/m4/metronome.s` takes that `ldrb.w` and gives preset ID 181 Volume/Pan's `0x10` (`Block_FXLoopThumb`, teal, with the block's own on/off). (2) The *block* category (0..`0x19`, records at `0x28e2815c`: name, short name, colour, dim colour, icon, off icon; getter `0x28d9e01c`) is not Table 2's byte 21 (which mirrors it) but the model's Entry 3 meta `category` (key `0x35`), read only by `0x28dff824`, which maps its string index (`modulation` `0xc6` → 7, `looper` `0xf83` → `0x17`, …) and gives `0x19` (Unknown) to a model without one: only the app, harness, mic and null models (34). The Metronome has no `category`, and `tools/features/metronome.py` makes `0x19` Metronome: teal, Icon_Tempo, and a dimmed copy as its off icon.
- The kernel counts samples since the last beat (100 ms .. 8 s, from pid 5 x 48000) and plays a 1 kHz sine (2 kHz on a downbeat) at half scale x Level, 6 ms decay. A new Time puts the next beat a new beat after the last. Its 142 instructions sit right under NAM's cold code, above NAM's three slots in Block 3 (`patch_click.pm_base`, from `nam_multi.Layout`); all its state is in its own instance words, DM(20..26) and DM(100..119).
