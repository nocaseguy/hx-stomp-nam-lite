# The feature engine

How a feature is built in: its module, its settings and Global Settings section, and the hooks it may share or own. Status tags as in [conventions.md](../conventions.md).

- **Features** (`tools/features/`, one module each, see its `__init__.py`): a feature declares its `SETTINGS`, its `FLAG` and its hooks (`apply`); `patch_menu.py` gives each enabled feature its own Global Settings category, writes the labels, limits (0..1: the stock enum entry; anything else: a snippet in the tail of the ID's long label slot, so labels stay short) and value text, and assembles its M4 `.s` at build time (`Patch.module`) with a generated `hxtra.inc` (`SETTING_<FEATURE>_<KEY>`, `_MAX`, `_DEFAULT`, and `HXTRA_SETTING_GET`, which clamps a stored value to the setting's range). Every write goes through `Patch.put`, which fails on overlap; a place several features hook (the Home paint, the DSP stream callback, a function's start) is shared with `chain_ptr`, `chain_bl` or `chain_entry`, one stub calling every feature's handlers around the stock function.
- **Beyond Entry 0 and on/off flags.** A hook no stub can share (a function with stack arguments, or a handler that rewrites them, such as the 9-argument text renderer at `0x28db7aa4`) is taken whole with `Patch.own_entry`: a plain `b.w` to the handler, the stock prologue moved to the cave as `hook.stock`, and a build failure if a second feature owns, chains or writes over it. `Patch.own_call` takes a single `bl` or `b.w` (a tail call) the same way, pointing it at the handler. `p.entry(n)` gives Entries 7 and 8 (the image store, read with `tools/image_store.py`) with the same overlap check; Entry 8 grows by `add_item`, which appends the items and a copy of the item table and repoints header words 2, 3 and 5, so no stock byte moves and readers must follow word 3. `p.add_glyph` fills an empty font slot that way. A feature's `FLAG` may be a tuple, and `INPUTS` (`features.Input`: text, a choice, a path, a `key=value` mapping) give it values from the environment, read with `p.input`.

The settings behind a feature: [m4/settings.md](../m4/settings.md). The M4 toolchain: [m4/toolchain.md](../m4/toolchain.md).
