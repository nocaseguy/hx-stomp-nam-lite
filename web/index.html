HX Stomp · HX Stomp XL · NAM A2 Lite

Put NAM captures on your HX Stomp

This page walks you through everything: building the firmware from your own Line 6 file, installing it, and turning your .nam captures into files the Stomp can play. It all runs in this browser. Nothing is uploaded anywhere.

Unofficial and experimental. This isn't made or supported by Line 6. Installing modified firmware is at your own risk and may void your warranty. If anything goes wrong, the Recovery steps put the stock firmware back; it has been done on a real unit.

Get ready

About 10 minutes in all. Tick these off as you go.

HX StompHX_Stomp_v3.80.0_0x103966115.hxf
HX Stomp XLHX_Stomp_XL_v3.80.0_0x103966115.hxf

Keep this stock file somewhere safe. You also need it for Recovery and to go back to the normal firmware later.

2

Build your firmware

Drop the stock file here. This page adds NAM A2 Lite to it and gives you a new file to install.

This step needs the page opened from a web address.

You opened the page as a file on your computer, and browsers don't let a file page run the build. Open the online page instead; it does the same thing and still uploads nothing. (Steps 4 and 5 work either way.)

Running it from a copy of the project? In its folder, run python3 -m http.server and open http://localhost:8000/web/, or use python3 build.py as in the README.

Technical details

    

    
The first build downloads the build tools (about 15 MB) and takes 20–60 seconds, depending on the computer. Keep this tab open until it finishes.

Install it with Line 6 Updater

      
The same way as a normal Line 6 update, with your new file.

    

    
    
      
  1. Close HX Edit, if it's open. Updater can't reach the Stomp while HX Edit is using it.
    2. 
      
  2. Connect the Stomp to the computer with USB and turn it on.
    3. 
      
  3. Open Line 6 Updater, sign in, and select your Stomp.
    4. 
      
  4. Choose Choose File (not the normal update) and pick the file you downloaded in step 2: HX_Stomp_v3.80.0_NAM_A2_Lite.hxf.
        
    On an XL, pick the file with _XL_ in its name. Never install the other unit's file.
    5. 
      
  5. Let it finish. Don't unplug or switch off the Stomp while it updates. It restarts on its own when done.
    6. 
    

    
Check it worked

    
On the Stomp, add an amp block and open the model list: there is a new folder, Amp › NAM, with NAM A2 Lite in it. Everything else is the same as stock 3.80.0.

    
Stuck on the splash screen after the install? Don't worry: follow Recovery.

  


  
  

    

      4
      
Convert your captures

      
The Stomp loads NAM captures from its User IR slots. This turns each .nam into a .wav that HX Edit can import there.

    

    

    

      
No captures yet

      

        
        
      

    

    

      
Converted captures appear here. Only the 3-channel A2 Lite size works (on ToneHunt and similar sites, look for “A2 Lite”). A .nam with several sizes in one file works too: its A2 Lite model is used.

    

    
The .wav isn't a sound: it carries the capture's 1,871 numbers. Don't load it into a Cab or IR block; it's for the NAM A2 Lite amp only.

  


  
  

    

      5
      
Load a capture and play

      
Import the .wav files with HX Edit, then point the amp at them.

    

    
    
      
  1. Open HX Edit with the Stomp connected, and open the Impulses list.
    2. 
      
  2. Drag a .wav from step 4 onto a free slot. Write down its number, for example 5.
    3. 
      
  3. Add an amp block and pick Amp › NAM › NAM A2 Lite.
    4. 
      
  4. Turn Model to that slot number. You hear the capture.
    5. 
    

    

      
KnobWhat it does

      
        
ModelWhich capture plays: the User IR slot (1–128) that holds it. A slot with a normal cab IR, or nothing, is silent.

        
DriveLevel into the capture, −20 to +20 dB. 5.0 is the capture's own level.

        
Bass Mid
Treble Presence		Tone controls after the capture, ±12 dB. 5.0 is flat.

        
Ch VolOutput level. 5.0 is unchanged; 10 is +12 dB.

      
    

    
    
      
  • The Model knob shows slot numbers, not names. Presets remember the number, so if you move a capture to another slot, update the presets that use it.
    • 
      
  • Changing Model, by hand or in a snapshot, switches smoothly with no gap.
    • 
      
  • One NAM A2 Lite at a time. A second one passes the sound through unchanged.
    • 
      
  • It is a heavy block (about the cost of the biggest stock amps), so the Stomp may grey out other heavy blocks next to it.
    • 
    

  


  
  

    

      !
      
Recovery, or going back to stock

      
If the Stomp stops at the splash screen, or you just want the normal firmware back.

    

    
    
      
  1. Turn the Stomp off.
    2. 
      
  2. Hold the Page Right button while you turn it on. It starts in update mode with a dark screen.
    3. 
      
  3. In Line 6 Updater, choose Choose File and pick the stock file from step 1 (HX_Stomp_v3.80.0_0x103966115.hxf).
    4. 
    

    
This works because the build never touches the Stomp's bootloader. It has restored stock 3.80.0 on a real unit after a modified firmware hung at the splash. To go back to stock without any trouble, just install the stock file with Choose File the normal way.

    
On an XL, use the stock XL file and Line 6's own update-mode procedure for the XL in place of Page Right.

Questions

    

    
Why do I need my own firmware file?
      
The firmware is Line 6's, so this project can't hand it out. This page takes your copy, changes four of its fifteen parts (the amp list, the model tables, the DSP program and its graph library), and fixes every checksum. The bootloader is never changed. Please don't share the file you build.

    
Is my file uploaded?
      
No. The build runs inside this browser tab. The only downloads are the page itself and the build tools; your firmware and captures never leave the computer.

    
How do I know the built file is right?
      
The build checks every checksum inside the firmware, then compares the result's fingerprint with the build the project tested. When they match, the page says Verified: your file is byte for byte the same as the tested one.

    
My capture says “No 3-channel A2 Lite model inside”.
      
NAM captures come in several sizes. The Stomp's DSP can run only the A2 Lite size. Look for the A2 Lite version of the capture, or a multi-size .nam that includes it.

    
The build says it isn't the right firmware.
      
  • It must be version 3.80.0, for your unit, exactly as Line 6 made it. Older or newer versions don't work.
    • 
        
  • Don't pick a file that was already built here (it ends in _NAM_A2_Lite.hxf).
    • 
        
  • If the file was renamed, that's fine: only its contents count.
