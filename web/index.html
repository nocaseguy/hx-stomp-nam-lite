HX Stomp · NAM A2 Lite

NAM to HX Stomp IR

Turn NAM A2 Lite captures into User IR files. Import them into the Stomp with HX Edit and pick them with the Model knob of the NAM A2 Lite amp. Your files stay in this browser; nothing is uploaded.

The Model knob shows slot numbers, not names. A number in front of each file name tells you which slot to import it into.

No captures yet

Converted captures appear here, each with the slot number to import it into. Only the 3-channel A2 Lite size works. A .nam with several sizes in one file works too; its A2 Lite model is used.

On the Stomp

  1. Drop your .nam captures here and download the .wav files.
  2. In HX Edit, open the Impulses list and drag each .wav onto the slot number in front of its name.
  3. Add Amp › NAM › NAM A2 Lite and turn Model to that slot number.

Good to know

The .wav is not a sound. It carries the capture's 1,871 weights, so don't load it into an IR block.

A slot that holds a normal cab IR is silent when Model points at it.

Needs the HX Stomp firmware with NAM A2 Lite built from the hx-stomp-nam-lite project.
