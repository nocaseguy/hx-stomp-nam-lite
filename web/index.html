Set up HXtra for HX Stomp

Setup instructions

Unofficial and experimental. HXtra isn't made or supported by Line 6. Installing modified firmware is at your own risk and may void your warranty. Don't worry though: if anything goes wrong, the Recovery steps put the stock firmware back easily.
  • No settings
  • Each block's title in the model browser and the Edit view names the gear it's based on: Deez One Mod becomes Boss DS-1 Mod. Line 6 originals keep theirs.

This copy of the page has no feature code, so it builds NAM A2 Lite and the boot screen only. The page published with each HXtra release has it.

Build HXtra

This step builds HXtra from the stock firmware file and gives you the modified firmware file to install.

This step needs the page opened from a web address.

You opened the page as a file on your computer, and browsers don't let a file page run the build. Open the online page instead: wisemandenny.github.io/hxtra. It does the same thing and still uploads nothing. (Steps 5 and 6 work either way.)

Technical details

    

    
The first build downloads the build tools (about 15 MB) and takes 20–60 seconds, depending on the computer. Keep this tab open until it finishes.

Try it without installing

    


      
Run HXtra from the unit's memory for one session. Nothing is written to the unit and no changes you make will save. Power cycling takes you back to stock.

      
    
        
  1. Your HX Stomp has Line 6's stock firmware 3.80.0 installed.
    2. 
        
  2. Use Chrome or Edge on a computer, and quit HX Edit and Line 6 Updater: they hold the USB connection.
    3. 
        
  3. Connect the HX Stomp with USB, turn it on and click Run from RAM (below). Pick the HX Stomp in the browser's list. As it restarts, the browser asks twice more: each time, click Continue and pick the device it lists.
    4. 
        
  4. If the HX Stomp isn't in the list, turn it off, hold Page › while you turn it on (update mode, dark screen), and click Run from RAM again.
    5. 
      

      
Knobs can react slowly in a RAM run; an installed firmware doesn't do that.

      
Every HXtra feature was tried this way on a real HX Stomp. On Windows the browser may not see the HX Stomp, because Line 6's driver holds it.

Install it with Line 6 Updater

      
The same way as a normal Line 6 update, with your new file.

    


    
Install

    
    
      
  1. Close HX Edit, if it's open. Line 6 Updater can't reach the HX Stomp while HX Edit is using it.
    2. 
      
  2. Connect the HX Stomp to the computer with USB and turn it on.
    3. 
      
  3. Open Line 6 Updater, sign in, and select your HX Stomp.
    4. 
      
  4. Choose Choose File (not the normal update) and pick the file you downloaded in step 2: HX_Stomp_v3.80.0_HXtra.hxf
    5. 
      
  5. Let it finish. Don't unplug or switch off the HX Stomp while it updates. It restarts on its own when done. This process can take up to 20 minutes.
    6. 
      
  6. Check it worked. If the boot screen says HXtra STOMP, then congratulations, the setup is complete!
    7. 
      
  7. Proceed to steps 5 and 6 only if using NAM.
    8. 
    

    
Stuck on the boot screen after the install? Don't worry: follow Recovery.

  


  
  

    

      5
      
Convert your NAM captures

      
The HX Stomp loads NAM captures from its User IR slots. This turns each .nam into a .wav that HX Edit can import there.

    

    

    

      

      

        
        
      

    

    

      
Converted captures appear here. Only the 3-channel A2 Lite size works (on ToneHunt and similar sites, look for “A2 Lite”). A .nam with several sizes in one file works too: its A2 Lite model is used.

    

    
The .wav isn't a sound: it carries the capture's 1,871 numbers. Don't load it into a Cab or IR block; it's for the NAM A2 Lite block only!

  


  
  

    

      6
      
Load a capture and play

      
Import the .wav files with HX Edit, then point the NAM A2 Lite block at them.

    

    
    
      
  1. Open HX Edit with the HX Stomp connected, and open the Impulses list.
    2. 
      
  2. Drag a .wav from step 5 onto a free slot. Write down its number, for example 5.
    3. 
      
  3. Add a block and pick Amp › NAM › NAM A2 Lite.
    4. 
      
  4. Turn Model (the first knob of page 3) to that slot number. You hear the capture.
    5. 
    

    

      
KnobWhat it does

      
        
ModelWhich capture plays: the User IR slot (1–128) that holds it. A slot with a normal cab IR, or nothing, is silent.

        
InputLevel into the capture, −20 to +20 dB. 5.0 is the capture's own level.

        
Bass Mid
Treble		Tone controls after the capture, ±12 dB each. 5.0 is flat. Bass is a low shelf at 150 Hz, Mid a band at Mid Freq, Treble a band at 2.5 kHz.

        
Mid Freq QWhere Mid sits, 150 Hz to 3 kHz (650 Hz by default), and how wide it is: Q 0.7 (wide), 1.4 or 2.8 (narrow).

        
High CutA low-pass filter. 10.0 is off; turning it down lowers the cutoff, to 2 kHz at 0.0.

        
OutputOutput level. 5.0 is unchanged; 10 is +12 dB.

        
PolarityNormal or Inverted: Inverted flips the output's polarity (phase).

      
    

    
    
      
  • Presets remember the model number, so if you move a capture to another slot, update the presets that use it.
    • 
      
  • Changing Model, by hand or in a snapshot, switches smoothly with no gap.
    • 
      
  • Maximum of two NAM A2 Lite blocks, each with its own capture, per preset, all from Amp › NAM. They don't count toward the HX Stomp's limit of two amps.
    • 
      
  • Each block uses about a quarter of the HX Stomp's DSP, so two leave room for more blocks. With the DSP meter, each block shows its share.
    • 
      
  • HX Edit shows it as Xenomorph Fuzz, with Xenomorph's knob names: Gain is Input, Tone is Treble, Level is Output, Clipping is Polarity, OscLevel is Bass, OscTone is Mid, MinFreq is Model, MaxFreq is Mid Freq, WaveShape is Q and Sensitivity is High Cut. It keeps NAM blocks and their settings when you move blocks around.

Recovery, or going back to stock

      
If the HX Stomp stops at the boot screen, or you just want the normal firmware back.

    

    
    
      
  1. Turn the HX Stomp off.
    2. 
      
  2. Hold the Page › button while you turn it on. It starts in update mode with a dark screen.
    3. 
      
  3. In Line 6 Updater, choose Choose File and pick the stock file from step 1 (HX_Stomp_v3.80.0_0x103966115.hxf).
    4. 
      
  4. Use HX Edit to restore the backup file you made in step 1 (File > Restore From Backup...).
    5.

Questions

    

    
Why do I need my own firmware file?
      
The firmware is Line 6's, so this project can't hand it out. This page takes your copy, changes a few of its fifteen parts (the main application, the DSP program and its graph library, the model list and the image store), and fixes every checksum. The bootloader is never changed. Please don't share the file you build.

    
Is my file uploaded?
      
No. The build runs inside this browser tab. The only downloads are the page itself and the build tools; your firmware and captures never leave the computer.

    
How do I know the built file is right?
      
The build checks every checksum inside the firmware, then compares the result's fingerprint with the build the project tested. When they match, the page says Verified: your file is byte for byte the same as the tested one.

    
Is there more than this page offers?
      
The command-line build (build.py) has a few more options: your own boot picture and boot text. See the README.

    
My capture says “No 3-channel A2 Lite model inside”.
      
NAM captures come in several sizes. The HX Stomp's DSP can run only the A2 Lite size. Look for the A2 Lite version of the capture, or a multi-size .nam that includes it.

    
The build says it isn't the right firmware.
      
  • It must be version 3.80.0, for your unit, exactly as Line 6 made it. Older or newer versions don't work.
    • 
        
  • Don't pick a file that was already built here (it ends in _HXtra.hxf).
    • 
        
  • If the file was renamed, that's fine: only its contents count.
