HX Stomp Icon Library

Every icon-like image in your stock firmware, drawn at 2× from its pixels by tools/icon_library.py. Each tile gives the image's name, its size in pixels and its index (the number the firmware uses for it). An HXtra feature picks its pages' icon by name with ICON; a name tagged in ICONS works as it is, any other needs its line in ICONS in tools/patch_menu.py (see docs/icons.md). An image marked fits is no bigger than 30×29, the size of the stock section icons; bigger ones may run into the title.

Shown by stock Global Settings

Section icon by the title

One per section, from the list at 0x28e3b5b8. An HXtra page shows its feature's ICON here, or the Displays icon when the feature names none.
